# ML laboratorinis 1: (ne)tiesinė regresija

Studijų darbas (mašininio mokymosi metodai). Kaip temperatūros poveikis dviračių nuomų skaičiui kinta per parą.

## Turinys
- `ataskaita.pdf`: ataskaita su grafikais ir išvadomis
- `1_dalis_dviraciai.ipynb`: regresija su dviračių nuomos duomenimis (valandos kodavimas sin/cos, sąveika su temperatūra, modelių palyginimas pagal R² ir RMSE, temperatūros poveikis skirtingomis paros dalimis)
- `2_dalis_klasifikavimas.ipynb`: klasifikavimo metodų palyginimas

Duomenų failai (`hour.csv`, `satellite_train.csv`, `satellite_test.csv`) neįkelti, reikia padėti šalia užrašų knygelių.

Įrankiai: Python, pandas, scikit-learn, statsmodels, seaborn.

- [exoplanet-classification-neural-network](https://github.com/simassss/exoplanet-classification-neural-network): Egzoplanetų klasifikavimas: neuroninis tinklas
